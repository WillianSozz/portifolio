# Portfólio — Willian Soares

## Como executar
1. Extraia os arquivos para uma pasta.
2. Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: cores, layout, responsividade e animações.
- `script.js`: menu mobile, alternância de tema, animações, navegação e formulário de contato.

## Antes de publicar
- Troque `seuemail@exemplo.com` pelo seu e-mail real no HTML e no JavaScript.
- Atualize os links do GitHub e LinkedIn com seus perfis.
- Substitua os projetos de exemplo pelos seus projetos reais e adicione links para os repositórios.
- Ajuste as descrições e os níveis de habilidade para refletir sua experiência real.

O formulário usa `mailto:` para preparar uma mensagem no aplicativo de e-mail do visitante. Para envio sem abrir um aplicativo de e-mail, conecte um backend ou serviço de formulários.
